# Background system notification

The approval request that reaches you with the app closed.

https://github.com/user-attachments/assets/f301b223-b84b-46fb-b01e-7a49ae90e09d

With the app backgrounded, a blocked agent raises a real system notification;
tapping it brings the app back to the pane that needs you.

This needs a secure origin (HTTPS) and the one-time notification permission —
which is the practical reason to expose the bridge through Tailscale or a
reverse proxy rather than plain HTTP.
