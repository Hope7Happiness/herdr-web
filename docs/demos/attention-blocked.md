# Blocked agent → toast → jump

The herdr feature people love, on a phone.

https://github.com/user-attachments/assets/265b1086-8129-47e4-b522-45f131329b91

An agent in another workspace hits an approval prompt: its dot turns orange,
a toast slides in, and the bell chip starts pulsing. Tapping the toast jumps
straight to the blocked pane.

Tabs are sorted by attention (blocked first, then done-unseen, then working and
idle), so the pane that needs you is never buried in a long strip.
