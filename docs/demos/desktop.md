# Desktop layout

The same single-page app at desktop size.

https://github.com/user-attachments/assets/aeca8a81-a05c-436f-ac39-c355a1a895bd

Nothing about herdr-web is phone-only: terminal rows wrap locally to whatever
viewport is connected, while the underlying PTY remains controlled by Herdr.

Prompt, watch the response stream, wheel-scroll into history, hop between
workspace tabs — same code path as the phone, no separate desktop build.
