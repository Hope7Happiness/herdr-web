# Done while you weren't looking

Finished work is tracked as unseen until you actually look at it.

https://github.com/user-attachments/assets/ade7844b-d78d-41d5-9a11-0a0f7b7fcdca

An agent finishing in a background pane is marked **done — unseen** with a blue
dot and a "finished" toast. The bell chip cycles you to the next agent that
needs attention.

Seen-state is synchronised both ways: herdr's own `done` status is honoured,
and viewing a pane here marks it seen in herdr too (via `agent.focus`), so the
two views never disagree about what you have already read.
